# Cantine — calcul de commande

**Nom :** SENE

Ce projet JavaScript calcule le prix total d'une commande à la cantine à partir
du code du plat et du nombre de portions. Il affiche le récapitulatif, puis
indique la monnaie à rendre ou le montant restant à payer.

## Exécution

Depuis le dossier du projet, exécutez :

```powershell
node cantine.js
```

Les sorties des trois scénarios de vérification sont disponibles dans
[`preuve.txt`](./preuve.txt).
